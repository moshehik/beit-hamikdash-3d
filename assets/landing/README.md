# איורי דף הכניסה (17.11.2026)

שבעה איורים בסגנון אחיד ("3D claymation / Pixar-like icon" לילדים), PNG שקוף 256x256, כל אחד עד 60KB.
קובץ = מפתח data-go של הכרטיס ב-`#landing`: tours (מנורה), model (בית המקדש), walk (ילד מטייל), ark (ארון הברית), map (מפה מגולגלת), kids (ילדים עם דגלים), about (מגילה + זכוכית מגדלת).

## איך הופקו
- מנוע התמונות של Gemini בשרת אורקל (`POST /ask`, `force:"image"`, פרומפט באנגלית; 9 קריאות בסך הכול: 7 + 2 תיקונים). כללי הצניעות הנסתרים נאכפים בשרת.
- הנחיית סגנון משותפת: סגנון חימר תלת־ממדי נוצץ, צבעים עזים, תאורה חמה, נושא ממורכז בכ-80% מהמסגרת, **רקע ירוק אחיד #00FF00** ללא טקסט; ילדים/גברים בלבוש צנוע מלא, בלי סמלים של דתות אחרות.
- הסרת רקע: `tools/landing-icons.py <תיקיית JPEG גולמיים בשם <מפתח>_*.jpg> assets/landing` (chroma key לפי דומיננטת ירוק + ניקוי קצוות + יישור ל-256x256; ל-kids סף מחמיר כי יש דגל ירוק).
- תיקוני הנחיה שנדרשו: "model" – הגרסה הראשונה יצאה עם כיפה (דומה למסגד) ולכן נוצרה מחדש עם "flat roof, no dome"; "kids" – הראשונה כללה כיסויי ראש מוסלמיים, ונוצרה מחדש (כיפות/צמות) ואז פעם נוספת בגלל שורה כפולה "רפאים".

## אריזה ושילוב
`node tools/pack-landing.cjs` -> `src/landing_icons.js` (`const LAND_ICONS`), ו-build.js כולל אותו. ב-`src/ui.js` (בלוק "דף כניסה") כל `[data-go]` שיש לו איור מחליף את האימוג'י ב-`<img>`; אם חסר – האימוג'י נשאר.
