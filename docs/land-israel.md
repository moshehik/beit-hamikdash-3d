# ארץ ישראל בתלת־ממד בימי בית שני (`ERETZ`)

מודל שטח של כל הארץ סביב ירושלים: יהודה, שומרון, הגליל, הגולן, עבר הירדן, השפלה, השרון, הנגב, הערבה וים המלח.
קוד: `src/eretz.js` (API וציור, נכלל בחבילה הראשית – כ־20KB), `src/eretz_data.js` (נתונים, **נטען עצלנית** – כ־0.6MB), מחוללים: `tools/land-dem.py` ו־`tools/make-eretz.py`.

## איך רואים
- באתר: בתפריט "מצב" כפתור **🗺️ ארץ ישראל בתלת־ממד** → המצלמה עולה מירושלים אל מבט־על של כל הארץ. חלונית שמאלית: קפיצה למקום, "כל הארץ", הסתרת שמות, "חזרה לדגם".
- בקונסולה / בסיור: `ERETZ.show()`.

## ה־API (לסיורים)
קנה המידה זהה ל־`src/world3d.js`: מעלה אחת = 1000 יחידות, ירושלים (35.2E, 31.8N) = הראשית, `x=(lon-35.2)*1000`, `z=-(lat-31.8)*1000`. זהו קנה מידה **קולנועי** (יחידה ≈ 111 מ'… ק״מ), לא קנה המידה של דגם המקדש (יחידה = אמה ≈ 0.5 מ').
כשהמודל מוצג והמצלמה גבוהה מ־`y≈1800` המודל המקומי של ירושלים מוסתר (הסולמות שונים פי ~222), וחוזר כשיורדים.

| | |
|---|---|
| `ERETZ.show({fly})` / `ERETZ.hide({restore})` | הצגה / הסתרה. `fly:false` – בלי תנועת מצלמה (לסיור שמזיז את המצלמה בעצמו); `restore:false` – בלי החזרת המצלמה |
| `ERETZ.on`, `ERETZ.loaded` | מצב הצגה; האם הנתונים נטענו ונבנו |
| `ERETZ.load()` | Promise – טעינת הנתונים (עצלנית). `show()` קורא לה |
| `ERETZ.pos(lat,lon)` | `{x,y,z}` – `y` = גובה הקרקע (מוגזם) |
| `ERETZ.elev(lat,lon)` | גובה במטרים (נתון SRTM / מים משוערים) |
| `ERETZ.kmUnit` | יחידות לק״מ (≈ 9) |
| `ERETZ.place(id)`, `ERETZ.places` | מקומות: `{id,he,lat,lon,x,y,z,kind,rank,conf:'sourced'\|'estimated',note}` |
| `ERETZ.camAt(id,height,tilt,az)` | `{pos,tgt}` למצלמה מעל מקום (גובה מעל הקרקע ביחידות; `tilt` 0=מלמעלה; `az` כיוון במעלות) – מתאים ל־`cam` בצעד סיור |
| `ERETZ.flyTo(id,{height,tilt,az,dur})` | טיסה פשוטה (לשימוש מחוץ למנוע הסיורים) |

מזהי מקומות (חלק): `jerusalem, olives, hebron, herodium, jericho, masada, qumran, engedi, machaerus, yavne, lod, jaffa, caesarea, sartaba, grofina, hauran, beitbaltin, gerizim, sebaste, shechem, beitshean, sepphoris, tiberias, capernaum, banias, hermon, …`
**חשוב לסיור ראש השנה:** `grofina`, `hauran`, `beitbaltin` הם `estimated` (הזיהוי לא ודאי); `sartaba` משוער במקומו.

## מקורות ומה נמדד לעומת מה הוערך

**נמדד (נתון אמיתי):**
- **גבהים:** SRTM דרך AWS Terrain Tiles (zoom 10, ~150 מ' לפיקסל; דגימה מחדש ל־0.0025° ≈ 270 מ'; רשת השטח 0.01° ≈ 1.1 ק״מ). קווי החוף של הים התיכון ושל מפרץ אילת לפי הנתון (בימי בית שני קו החוף דומה בקירוב; שינויים מקומיים לא מומדלו).
- **הצללה (hillshade)** מחושבת מנתוני הגובה.
- **מיקומי ערים** – קואורדינטות של האתרים הארכאולוגיים המקובלים (מזיכרון, לא נבדקו אחד־אחד; סטייה של ק״מ בודדים אפשרית).

**מוערך (לא מדידה):**
- **מפלס ים המלח**: הוגדר ל־395− מ' (כ־35 מ' מעל היום; הקו האמיתי בימי בית שני שנוי במחלוקת, ~390−…400−), והאגן הדרומי כ"לגונה" רדודה. **מפלס הכנרת** 208− מ'. **אגם החולה** (שהתייבש במאה ה־20) והביצות (חולה, שרון, קישון, ירקון, אזור עזה, דרום ים המלח) – מצוירים לפי תיאורים היסטוריים, צורתם משוערת.
- **צבעוניות וצמחייה**: מודל גשמים פשוט (קו רוחב, מרחק מהים, הגבהה, צל גשם) → צבע לפי אזור אקלים; חורש ים־תיכוני, שדות, דיונות, בזלת (גולן, בשן/חורן, גליל תחתון – קווי המתאר משוערים), הר החרמון עם שלג, מצוק מלח/מרל בים המלח. אין ספרות לצמחייה ברמת הפיקסל.
- **נהרות ונחלים**: מסלולים משוערים (הירדן, ירמוך, יבוק, ארנון, חסה, קדרון, שורק, ירקון, אלכסנדר, קישון, חרוד, בשור…).
- **דרכים**: רשת משוערת של דרכי המסחר והדרכים הרומיות/הרודיאניות הידועות (דרך הים – ויה מריס, ירושלים–יריחו, ירושלים–חברון, ירושלים–בית חורון–לוד, ירושלים–אלתרופוליס, דרך ההר שכם–בית שאן, דרך הקטורת עזה–באר שבע–עבדת–פטרה ועוד).
- **גבולות אזורים** ושמות האזורים (יהודה, שומרון, גליל…) – סימון כללי בלבד, לא גבולות פוליטיים.
- סמלי הערים והמבצרים (הרודיון, מצדה, נמל קיסריה…) הם **סמליים** וגדלים עם המרחק; לא תבנית אמיתית.
- ההגזמה האנכית: ×5.5 (גובה = (מ'−740)·0.055 יחידות); המישור המזרחי (ערב) אינו נבדק.

## רקע קבוע – הארץ כאופק (`ERETZ.bdDraw`, 22.11.2026)
בכל מצב רגיל של האתר (לא בתצוגת "ארץ ישראל בתלת־ממד" המפורשת) הארץ כולה מצוירת כ**אופק רחוק** מאחורי המודל המקומי: מהר הבית רואים (מגובה מספיק) את הרי יהודה, מדבר יהודה, ים המלח והרי מואב, כחלק מעולם אחד. אין צורך ללחוץ על הכפתור.
- **איך**: מעבר ציור נפרד. סצנה ומצלמה משלה (אותו כיוון ומיקום כמו המצלמה הראשית; אמות → מטרים ×0.5), רשת השטח בקנה מידה **אמיתי** (מטרים, ראשית = הר הבית ב־31.7785N 35.2345E, גובה 0 ≈ 740 מ'), מישור חיתוך (far) רחוק עד 900 ק״מ. אחריה `renderer.clearDepth()` וציור הסצנה הראשית מעליה (`scene.background=null`). לכן אין בעיות עומק, אין `camera.far` ענק בסצנה המקומית, והמודל המקומי תמיד מכסה את הרקע.
- **תפר**: בתוך ~1.75 ק״מ מההר גובה הרקע = `terrH` (השטח המקומי), ומ־5.5 ק״מ נתוני SRTM (בהדרגה). עד 2.6 ק״מ מההר הערפל והגוון זהים לשטח המקומי, ואז הוא מתפוגג לערפל־אופק (אקספוננטי, חוזר לצבע השמיים). בקצה הנתונים (קו חוף / רחוק) מתמזג לערפל – אין קצה קשה. ההרים הרחוקים מוגזמים בגובה ×2.2 (בהדרגה עם המרחק).
- **יום/ערב/לילה**: צבע הערפל והשמיים נלקחים מהסצנה הראשית (`scene.background`/`fog`), והבהירות מ־`day` ומצבע השמש.
- **רשת**: צפופה (120 מ') ליד ההר ומתרחבת עד פי 2 מרזולוציית הנתון (≈111K קודקודים, ≈220K משולשים, ציור אחד, חומר בלי תאורה).
- **כבוי** ב־`LITE`, ב־`?backdrop=0` (נשמר ב־`localStorage bh_backdrop=0`; `?backdrop=1` מחזיר), ובקונסולה `ERETZ.backdrop(false)`. כבוי אוטומטית בתצוגת הארץ המפורשת (`ERETZ.on`, כולל סיור ראש השנה), במפת העולם של סיור יום הכיפורים (`WORLD.gOn`) ובמצלמה גבוהה מ־9000 אמות. כל כשל (נתונים, WebGL, שגיאת ציור) = אין רקע, בלי שגיאות באתר.
- **טעינה**: ברקע אחרי שהמודל מוכן (טעינת הנתונים רק אחרי הסרת מסך הטעינה, ב־idle), ומופיע בהדרגה (fade ≈1.6 שנ').
- **נטפרי/אתרוג**: באתר החי הנתונים נשלחים כבייטים אטומים `p/eretz.<hash>.bin` (gzip, `application/octet-stream`; מיכל `[אורך כותרת][כותרת JSON][PNG גבהים][WebP מרקם]`, ≈0.3MB) ומפוענחים ב־`DecompressionStream`; בלי קובץ `.js`/`.json`/תמונה חיצוני. בבנייה לקובץ יחיד (`node build.js`) הנתונים מוטמעים כמו קודם.
- **מה שהרקע לא יכול**: מגובה הקרקע במדרון הר הבית הרכס של הר הזיתים (בשטח המקומי, +86 מ' ב־650 מ') מסתיר את מזרח – מואב וים המלח נראים ממצלמה גבוהה יותר (סיור, מבט־על) או מצפון/דרום להר הזיתים.

## ביצועים
- נטען עצלנית: בלחיצה (`ERETZ.load()`) או כרקע קבוע (ראו למעלה). בבנייה לקובץ יחיד (`build.js` רגיל) הנתונים מוטמעים (זה הקובץ לגיטהאב/הורדות); בפרסום (`site/publish.mjs`) הם `p/eretz.<hash>.bin` אטום (ראו למעלה).
- התצוגה המפורשת: רשת 340×460 קודקודים (156K), חומר בלי תאורה (MeshBasic) – הצללה אפויה במרקם.
- הרקע: ציור אחד נוסף, ≈220K משולשים (מול ≈5–13 מיליון משולשים ו־3000–10000 ציורים של המודל המקומי).

## הפקה מחדש

```
node build.js                # (או OUT=... node build.js)
```
