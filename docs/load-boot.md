# טעינה מהירה: דף ראשון זעיר + מטען נשמר במטמון (22.11.2026)

## הבעיה
`publish.mjs` פרסם את כל האתר בתוך `index.html` אחד (2.66MB מכווץ) כי הסינון (נטפרי/אתרוג) שיבש קבצי JS חיצוניים.
סינון שמחכה לכל התגובה לפני שהוא מעביר אותה = **מסך ריק** עד שהכול ירד; "טוען את בית המקדש…" לא הופיע.
בדיקה: גזירת הגדלים (gzip): vendor 0.15MB · תמונות/אייקונים 1.11MB (base64 של PNG ממילא דחוס; גם בינארי גולמי היה יוצא אותו דבר אחרי gzip, לכן לא שינינו) · data 0.07MB · app 0.33MB · תמונות מפה 0.97MB. ההקראות (5.8MB) כבר יושבות בקבצי `/a/*.mp3` נפרדים ונטענות לפי דרישה.

## הפתרון (ברירת המחדל של `node publish.mjs`)
* `index.html` = ~24KB מכווץ: CSS + סימון + מסך הטעינה עם **סרגל התקדמות** + `site/boot.js`. מצייר מיד.
* `boot.js` מביא **בייטים אטומים** `/p/<שם>.<hash>.bin` (`application/octet-stream`, כבר gzip בעצמם) עם `fetch`, כך שמסנן שמשכתב JS לא נוגע בהם;
  מציג התקדמות אמיתית (בייטים שהתקבלו / גודל צפוי), בודק שהגודל מדויק ושה-CRC של gzip תקין (`DecompressionStream`), ומריץ את הקוד
  כאלמנטי `<script>` שנוצרים בזמן ריצה (המסנן לא רואה אותם).
* מטמון: Cache API (`bh1`) לפי hash בשם הקובץ – ביקור חוזר = כמעט 0 בייטים (נמדד: 23KB, `hit:2`). בלי service worker (זה בסשן ה-PWA). קבצים ישנים נמחקים.
* חלוקה: `base` (three+אייקוני דף הבית+נתונים, כמעט לא משתנה → נשאר במטמון גם אחרי עדכון) · `app` (הקוד שלנו) → קריטי **0.90MB** (היה 2.66MB).
  `icons2` (175 איקוני חימר, 0.78MB) ו-`mapimg` (תמונות מפה, 0.97MB) נטענים ברקע אחרי שהמודל עלה (`window.__icon2Ready`, `onMapImgs`).
* גיבוי אוטומטי: כל כשל (רשת, 404, גודל, CRC, SyntaxError, אין DecompressionStream) → מעבר ל-`/full.html` (המסמך הבודד הישן; נשמר באותו פרסום).
  נכשל פעם אחת → דגל ל-24 שעות במכשיר (`bh_full`) שמדלג על המסלול המהיר. `?full=1` מכריח את הגרסה המלאה ידנית.
  שגיאת ריצה רגילה (למשל אין WebGL) לא מפעילה גיבוי.
* טלמטריה: אירוע `boot` ({ok, ms, net, run, hit, kb}) דרך `window.__bhEv` (נוסף ל-`tracker.js`).

## דגלים
`node publish.mjs` (ברירת מחדל = מצב boot, שלב 3) · `--stage 0..3` כמו קודם · `--inline` = ההתנהגות הישנה · `--chunks` = `<script src>` חיצוני (כבוי) · `--out <dir>` בדיקה מקומית.
שרת מקומי לבדיקה: `serve.js` לא השתנה (`p/*.bin` נשמרים עם `gzip=false`, `immutable`).

## מה נבדק / מה לא
נבדק בכרום headless (swiftshader, מחשב עמוס): המודל עולה דרך boot, אייקונים נטענים ומוחלפים, תמונות מפה נטענות, מטמון מדווח `hit`, גיבוי עובד ל-bin פגום ול-404.
לא נבדק: הסינון האמיתי (נטפרי/אתרוג/רימון) – ייתכן שגם `/p/*.bin` ייחסם; במקרה כזה הגיבוי ל-`/full.html` יפעל אבל אז חוזרים לבעיה הישנה. מספרי זמן בגלל עומס המחשב אינם מייצגים; ראו בדוח.
