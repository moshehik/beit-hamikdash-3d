# אפליקציה מותקנת (PWA) + שלט מצגות — 22.11.2026

## מה נמצא כשבדקנו למה "הריבוע מתפקד כ-Tab והחיצים גוללים"
הדפדפן **לא** חוסם את המקשים. הקוד ב-`src/remote.js` פשוט היה כתוב כך ש**בדף הכניסה** (landing) ובחלונות מפות/שבטים/"על הדגם" הוא
`return` מוקדם והשאיר את המקשים הרגילים: PageUp/PageDown גוללים את הדף, Tab מזיז פוקוס בין הכפתורים. משה היה בדף הכניסה (בגרסת GitHub Pages)
ולכן ראה בדיוק את זה. בטיול ברגל / סיור / מבט־על השלט עבד (נבדק עם אירועי מקלדת אמיתיים דרך CDP).

## מה תוקן ב-`src/remote.js`
| מסך | PageDown / PageUp (חצים) | ריבוע (Tab) / כפולה (Enter) | ארוכה (B / Esc) |
|---|---|---|---|
| דף הכניסה | מזיזים סימון זהב בין הכרטיסים | פותח את הכרטיס המסומן (אם אין סימון – הראשון) | — |
| רשימת הסיורים | מזיזים סימון בין הסיורים | מתחיל את הסיור המסומן | B סוגר את הרשימה |
| סיור | הבא / הקודם | הפעלה / השהיה | B הפעלה/השהיה |
| טיול ברגל | פנייה 30° (ימינה/שמאלה) | התחלת/עצירת הליכה קדימה; Enter = אחורה | B עצירה, Esc יציאה |
| מבט־על | סיבוב המבט | קירוב / הרחקה | B עצירה |
| מפות / שבטים / על הדגם | גלילה רגילה | ריבוע או B – סוגר וחוזר | Esc סוגר (כמו קודם) |

* הפנייה בטיול ברגל הייתה "החזקת מקש ווירטואלי 330ms" – במחשב איטי (פריים לשנייה) הפנייה לא התבצעה. עכשיו היא אנימציה לפי זמן שמגיעה תמיד ל-30° מדויקים (וכמה לחיצות ברצף מצטברות).
* חזרות של לחיצה ארוכה על הריבוע (Tab חוזר) מסוננות 700ms (כמו קודם), גם אחרי בחירת כרטיס.

## ה-PWA (התקנה כאפליקציה) — `site/pwa/`
* `manifest.webmanifest` (עברית, rtl, `display: standalone`, אייקונים 192/512/maskable מ-`tools/make-pwa-icons.py` על איור המקדש).
* `sw.js` – service worker גנרי: דף = רשת קודם (4 שניות) ואז העותק האחרון (נפתח גם בלי אינטרנט); `/a/*.mp3`, `/j/*.js`, `/pwa/*` = מטמון קודם.
  בקשות Range (שמע) עוברות לרשת. אם משהו נכשל – הדפדפן עושה fetch רגיל.
* `pwa.js` – נכנס inline ל-head: רושם את ה-SW 1.5 שניות אחרי הטעינה (לא מעכב את העלייה), כפתור "⬇ התקנה כאפליקציה" (`beforeinstallprompt`)
  וכפתור "⛶ מסך מלא" (במסך מלא: `navigator.keyboard.lock(['Tab','PageUp','PageDown','Enter','KeyB'])`). הכפתורים מופיעים רק בדף הכניסה.
  **מתג חירום:** לפתוח את האתר עם `?nosw=1` – מבטל את ה-SW וממחק את המטמון שלו.
* **שמות עם hash**: `/sw.<hash>.js`, `/pwa/manifest.<hash>.webmanifest`, `/pwa/icon-*.<hash>.png`. סיבה: `api/serve.js` נותן לכל קובץ שאינו HTML מטמון `immutable` של שנה
  (גם בקצה של Vercel), אז `/sw.js` קבוע לא היה אפשר לעדכן. כך אין שום שינוי ב-`serve.js` / `vercel.json` ולא צריך deploy – הכול דרך `publish.mjs`.
* פרסום: `node publish.mjs --pwa` (כבוי כברירת מחדל כדי לא לשבש את הבדיקה המדורגת מול אתרוג: `--stage`).
* בדיקות מקומיות (Chrome headless): `Page.getInstallabilityErrors` = ריק; SW פעיל ושולט אחרי רענון; האתר נפתח במצב offline; כשה-SW וה-manifest חסומים (403) האתר נטען רגיל ללא שגיאות (נשאר רק כפתור מסך מלא).

## מגבלות
* הכפתור "התקנה" יופיע ב-Chrome רק ב-https (Vercel) או localhost. בגרסת GitHub Pages אין PWA (נתיב משנה + בנייה אחרת) – לא נבנה.
* `keyboard.lock` עובד רק במסך מלא; Esc במסך מלא תמיד יוצא ממסך מלא (Chrome) – לכן Esc לא ננעל.
* אם הלחיצות לא מגיעות לדף כלל (הפוקוס בשורת הכתובת או באפליקציה אחרת) אף קוד באתר לא יעזור – בחלון מותקן אין שורת כתובת, וזה העיקר ביתרון של האפליקציה.
* חלופה אם צריך: תוכנית קטנה ב-Windows שקוראת את השלט (GetAsyncKeyState) ושולחת לדף דרך WebSocket מקומי – לא נבנתה.
